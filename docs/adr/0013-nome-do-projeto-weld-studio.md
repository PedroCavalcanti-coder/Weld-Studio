# ADR-0013: Nome do projeto: Weld Studio

- **Status:** Aceita
- **Data:** 2026-10-01

## Contexto

O nome provisório precisava ser fixado antes de existir código que dependa dele (namespaces, menus, extensão de arquivo).

## Decisão

O projeto se chama **Weld Studio**, o mesmo nome do repositório. Namespaces usam `WeldStudio`, menus usam `Weld Studio/...`, presets usam a extensão `.weld.json` e labels de Addressables usam o prefixo `weld.`.

## Consequências

- Resolve a questão em aberto Q1.
